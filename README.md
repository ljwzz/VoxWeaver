# VoxWeaver（声织）

VoxWeaver 是面向长篇小说和叙事文本的多角色有声内容制作桌面工具，覆盖文本整理、剧本转换、角色与声音配置、语音生成、质量审核、章节装配、同步阅读和导出。

## 产品流程

```mermaid
flowchart LR
    A["创建项目"] --> B["导入小说"]
    B --> C["校对文本"]
    C --> D["整理剧本"]
    D --> E["管理角色"]
    E --> F["配置声音与发音"]
    F --> G["生成语音"]
    G --> H["审核音频"]
    H --> I["合成章节"]
    I --> J["同步阅读"]
    J --> K["导入导出与发布"]
```

## 体验原则

- 原始素材完整保留，处理结果以新版本保存。
- 每个步骤提供清晰的输入、操作、结果和历史记录。
- AI 提供候选与证据，用户完成审核与确认。
- 局部修改对应局部更新，并展示后续影响。
- 正式制作使用来源与授权记录完整的素材。
