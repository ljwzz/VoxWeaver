# VoxWeaver（声织）

VoxWeaver 是一款面向长篇小说和叙事文本的多角色有声内容制作工具。

项目目标是建立一套完整、可编辑、可审核、可追溯的有声内容制作流程，从小说文本整理开始，逐步完成剧本整理、角色管理、声音配置、语音生成、质量审核、章节装配和同步阅读。

## 制作流程

```mermaid
flowchart LR
    A["创建项目"] --> B["导入小说"]
    B --> C["校对文本"]
    C --> D["整理剧本"]
    D --> E["管理角色"]
    E --> F["配置声音与发音"]
    F --> G["生成语音"]
    G --> H["审核音频"]
    H --> I["合成章节"]
    I --> J["同步阅读"]
    J --> K["导入导出与发布"]
```

## 主要能力

VoxWeaver 计划覆盖以下制作环节：

* 导入和整理长篇小说文本。
* 识别章节、场景及其他内容结构。
* 辅助发现并修正文本问题。
* 将小说整理为适合多角色朗读的剧本。
* 识别和维护角色、别名及不同角色阶段。
* 为主要角色保持稳定的声音表现。
* 为普通角色提供具有辨识度的声音配置。
* 管理专名、多音字、数字等朗读方式。
* 按剧本内容生成和调整语音。
* 对生成结果进行文本和听感审核。
* 将独立语音片段装配为完整章节。
* 建立音频与文本之间的时间对应关系。
* 导出成品、同步阅读数据和可继续制作的工程信息。

## 产品原则

* **保留原始素材**
  原始内容不被后续处理直接覆盖。

* **结果可追溯**
  重要处理结果能够追溯到对应的输入、修改和审核过程。

* **AI 辅助，用户确认**
  AI 负责分析、生成候选和发现问题，重要结果由用户确认。

* **支持局部修改**
  单个章节、角色、声音或语音片段发生变化时，应尽量只影响相关内容。

* **明确处理状态**
  用户能够知道哪些内容尚未处理、需要审核、已经完成或因上游修改而需要重新确认。

* **面向长篇内容**
  项目设计需要支持跨章节角色一致性、声音一致性和长期制作。
