## 1. 文档定位

本文件把 M1 拆成可独立实现、测试和交接的任务卡，不替代 `项目计划.md`、阶段 01 或阶段 90。

权威顺序统一遵循 [无人值守执行协议第 2 节](../无人值守执行协议.md#2-权威顺序)。本文件只列出 M1 相关上位输入，不定义另一套顺序：

1. `项目计划.md` 的产品范围和 M1 完成定义；
2. `docs/spec/01.小说导入与文件预处理.md` 的领域要求；
3. `docs/spec/00.项目基线与工程工作区.md` 的工作区、任务、产物和过期规则；
4. 本文件的实现顺序、文件边界和验证命令。

发生冲突时停止任务并上报，不得由执行模型自行扩大范围或修改上位文档。

## 2. M1 边界

M1 的完成标志只有：

- TXT 可以完整导入；
- 章节阅读顺序正确；
- 章节和文本块可以反查原始来源；
- 全部输入范围进入正文、前后置内容、噪声、附录、未知或待审核分类；
- 覆盖率、异常和人工调整结果可以查看并追溯；
- 重新执行不会覆盖源资产或已提交 revision。

M1 包含 `extracted/raw`、`canonical`、`normalized`，但不包含 `corrected`、`script` 或 `spoken`。

以下属于阶段 01 后续完成范围，但不阻塞 M1 里程碑：

- EPUB 导入；
- Markdown 导入；
- LLM 章节边界回退；
- 阶段 01 的扩展格式和完整基准数据集。

M1-D01 已确认 Scene 与 `ProcessingSegment` 由 M2 桥接切片交付；M1 任务不得顺手实现它们。

## 3. 小模型执行协议

每次执行只领取一个任务 ID。不得把相邻任务合并为一次实现。

开始任务前必须：

1. 读取仓库根 `AGENTS.md`、本文件及任务卡列出的输入文档；
2. 运行 `git status --short`，记录已有 modified、untracked 和 staged 文件；
3. 核对全部前置任务的完成证据和 Decision Gate；
4. 只打开任务卡要求的源码；找不到目标符号时才扩大只读搜索；
5. 确认没有其他改动占用任务卡的写入文件。

执行时必须：

- 只修改“允许写入”中的文件；
- 公共类型从 `src/index.ts` 导出，文件名使用 camelCase，包目录使用 kebab-case；
- 测试放在对应包的 `test/*.test.mjs`，从构建后的 `dist` 导入；
- 先写失败夹具或测试，再实现最小代码；
- 只使用现有依赖；需要新增依赖时停止并触发对应 Decision Gate；
- 不修改 `项目计划.md`、阶段 00～11、阶段 90、ADR 或 `docs/ideas/`；
- 不执行 `git add`、`git commit`、`git reset`、清理用户文件或批量格式化；
- 不把文档完成、Mock 通过或静态检查通过写成 M1 已完成。

任务结束前必须：

```bash
git diff --check
git status --short
```

并按以下格式交接：

```text
任务：M1-XX
结果：complete | blocked | failed | not_applicable
修改文件：逐项列出
验证：命令及退出码
未验证：逐项列出
既有改动：说明是否保持不变
阻塞：Decision Gate、错误文本或缺失输入
```

派发者应为小模型组装最小上下文包，只包含：本文件第 2～5 节、选中的单一任务卡、已关闭门禁的证据、任务涉及的当前接口，以及任务开始时的 `git status`。不得一次附带 M1 全部源码或让执行模型同时规划下一任务。

## 4. 公共不变量

所有任务共同遵守：

- 原始文件和已登记 `SourceAsset` 不可原地修改；
- 正式产物只能在完整校验后通过阶段 00 workflow 提交；
- 适配器只做格式探测、验证和提取，不做校对、角色推断或音频处理；
- `rawText`、`canonicalText` 和 `normalizedText` 不得共用可变文件；
- 文本范围统一使用半开区间 `[start, end)`，并在契约中显式声明 offset 单位；
- offset、行号、标题和显示顺序是定位属性，不是稳定实体 ID；
- 规则无法确定时产生 issue/review，不得猜测后写入正式索引；
- 任意删除或替换都必须有结构化 diff；
- Chapter 和块范围必须单调、不重叠；未覆盖范围不得静默丢弃；
- 相同输入、处理器版本和参数必须得到相同输入指纹；
- 失败重试不得覆盖已提交 revision，也不得自动删除旧产物。

统一错误码至少包括：

```text
NOVEL_IMPORT_UNSUPPORTED_FORMAT
NOVEL_IMPORT_INVALID_SOURCE
NOVEL_IMPORT_ENCODING_REQUIRED
NOVEL_IMPORT_STRUCTURE_INVALID
NOVEL_IMPORT_REVIEW_REQUIRED
NOVEL_IMPORT_STALE_SESSION
NOVEL_IMPORT_DEPENDENCY_UNAVAILABLE
```

新增错误码必须先进入契约测试，禁止在各适配器中创建同义错误码。
