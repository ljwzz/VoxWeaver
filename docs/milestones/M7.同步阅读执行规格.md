[Electron 架构规格](../architecture/electron-desktop-architecture.md) 是辅助设计输入，只能在与上述权威输入一致时使用。低层文件不得静默覆盖高层文件；冲突无法通过保持更窄范围解决时停止并上报 `blocked`，执行模型不得自行修改上位范围或填写人工决策。

## 2. 范围与非目标

### 2.1 M7 范围

- 从一个当前 `ChapterAssembly` revision 生成稳定的 ScriptUnit 级时间轴；
- 保存每个条目的章节、ScriptUnit、角色、显示文本、ClipRef 和整数毫秒范围；
- 校验时间范围单调、非负、不越过章节时长并可双向反查；
- JSON 作为项目内完整契约，WebVTT 和 SRT 作为派生兼容导出；
- 提供播放、暂停、倍速、拖动、章节切换和当前 ScriptUnit 高亮；
- 支持点击文本跳转音频、音频进度定位文本；
- 显示 `stale`、缺失、部分生成和项目切换状态；
- 保存 timeline revision、输入 assembly revision、序列化器版本和输出 hash。

### 2.2 非目标

- 不在 MVP 实现逐字或逐词强制对齐；
- 不修改章节音频、ScriptUnit、角色注册表或上游文本；
- 不把 WebVTT/SRT 回导为项目真值；
- 不实现移动端、网页端、云播放器、在线协作、书签或笔记；
- 不让 Renderer 读取绝对路径或跨项目复用旧播放状态；
- 不因显示样式变化使数据时间轴或音频过期；
- 不把角色头像、主题、Scene 面板等增强能力塞入 M7。

## 3. 小模型执行协议

每次只执行一个任务 ID。派发前必须同时检查本文件全部 Gate、任务卡前置、DAG 和文件占用；文件头“当前门禁”只摘要上游入口，不是完整派发依据。Gate 打开时，“未关闭时仍可执行”是唯一白名单，不得把阻塞列表的补集视为可执行。某分支被阻塞时可继续其他无依赖分支；所有白名单分支耗尽后，必须交付阻塞清单、已完成证据和下一可执行任务。

任务状态只允许：`pending`（未检查/未派发）、`ready`（前置、Gate、文件占用均满足）、`in_progress`（已被唯一执行者领取）、`complete`（单一结果和必测证据齐全）、`blocked`（缺决策/依赖/环境/上游契约）、`failed`（实现或验证失败且有证据）、`not_applicable`（已关闭条件分支明确排除）。禁止使用其他同义状态。

最小上下文与开始检查：

1. 读取根 `AGENTS.md`、本文件第 2～5 节、当前任务卡、已关闭 Gate 证据和涉及的当前接口/schema；
2. 运行 `git status --short`，记录既有 staged、modified、untracked 文件及并发占用者；
3. 核对 M6 稳定交付、全部前置、Gate、条件分支和 DAG；
4. 记录输入文件与 baseline revision/hash，只在找不到卡片符号时扩大只读搜索；
5. 先运行最窄既有测试；基线已失败时记录关联性，不得顺手修复无关失败。

执行与并发规则：

- 只修改任务卡“允许写入”的精确白名单；目录通配只适用于卡片明确授权的新包骨架、固定夹具或单一 Renderer feature；
- 同一可写文件同一时间只属于一个任务；共享 `src/index.ts`、package manifest、lockfile、公共 schema、App Core 和桌面路由的任务必须串行，占用在验证和交接完成后释放；
- 后完成的任务不得覆盖先完成任务的接口；发现接口漂移时立即停止，重新审计前置、基线 revision/hash 和文件占用；
- 先写失败测试或冻结夹具，再写最小实现；公共类型从目标包 `src/index.ts` 导出，测试从 `dist` 导入；冻结夹具/expected 后续只读；
- 不新增依赖、显示 profile、序列化行为或时间轴编辑能力，除非任务卡和已关闭 Gate 明确允许；需要未批准输入时立即停止相关分支；
- 不修改主计划、`docs/spec/`、ADR、`docs/ideas/`、其他里程碑规格、冻结 schema 或其他任务 expected；
- 不执行 Git 暂存、提交、重置、清理或无关格式化；单元测试和 Mock 不得替代真实播放与桌面交互证据；
- 验收任务不得修改实现、测试、夹具、expected、schema 或状态，不得自行报告 M7 完成。

Decision Gate 的本地候选、已选策略和关闭材料全部以第 5 节为准。候选策略冻结不等于 Gate 关闭；只有决策记录、全部 profile/版本/规则、批准夹具、可复制验证步骤、成功/失败判定、证据路径、执行环境和负责人均齐全时才可关闭。任一材料缺失时保持 `open`，不得猜测或改选。

验证层级：L1 为目标模块/纯函数测试，L2 为目标 package build/typecheck/test，L3 为跨 package integration，L4 为 `pnpm run check`，L5 为真实播放、桌面交互或目标播放器样本。只声明实际完成层级；L1～L4 不替代 L5。任务结束前必须运行：

```bash
git diff --check
git status --short
```

交接格式：

```text
任务：M7-XX
结果：complete | blocked | failed | not_applicable
修改文件：逐项列出
验证层级：L1～L5
验证：命令、退出码和关键断言
模型调用：none | mock | live-approved
输入基线：revision/hash
未验证：逐项列出
既有改动：是否保持不变
阻塞：Gate、缺失契约或原始错误文本
下一可执行任务：只列前置、Gate 和文件占用均满足的 ID
```

里程碑完成只能由负责人在独立变更中依据以下证据确认：所有必需任务 `complete`；条件任务 `complete` 或有已关闭 Gate 支持的 `not_applicable`；全部 Gate `closed`；冻结夹具 hash 未变化；package、integration 和全仓检查通过；真实播放、格式和桌面交互证据齐全或被上位范围明确排除；不存在未解决阻断、未知数据丢失或未记录范围扩张。执行模型不得自行更新里程碑状态。

## 4. 公共不变量

- `ChapterTimeline` 必须绑定一个明确、不可变的 `chapterAssemblyRevisionId`；
- JSON timeline 是项目真值；WebVTT/SRT 只能从同一 revision 派生，不能反向覆盖 JSON；
- 公共范围使用整数毫秒半开区间 `[startMs,endMs)`；条目按 `startMs`、`order` 稳定排序；
- 每个条目必须反查到 `sourceClipRefId`、`audioArtifactRevisionId` 和 `scriptUnitId`；
- 范围非负、开始小于结束、不越过章节时长；是否允许重叠必须由契约明确，不能由播放器偶然行为决定；
- 显示文本层、角色前缀和时间舍入策略必须版本化并进入 timeline/export 指纹；
- speaker 显示名变化不得改变音频时间，必要时只生成新的显示导出 revision；
- assembly revision 变化只使对应章节 timeline 和字幕过期；
- 章节顺序变化只影响全书目录/发布清单，不使未变单章 timeline 过期；
- 序列化必须确定性；相同输入、schema 和 serializer version 产生相同字节和 hash；
- 生成结果先写任务 tmp，校验后才提交；旧 timeline 和字幕不覆盖；
- 播放状态至少按 `projectSessionId + chapterId + timelineRevisionId` 隔离；项目切换后停止旧音频并拒绝旧事件；
- Renderer 只使用受控 artifact URL，不持有绝对路径，不自行推断正式 revision；
- 未关闭门禁时不得用默认显示层、前缀或编辑行为继续实现。

统一错误码至少包括：

```text
TIMELINE_ASSEMBLY_NOT_CURRENT
TIMELINE_INPUT_INCOMPLETE
TIMELINE_RANGE_INVALID
TIMELINE_MAPPING_MISSING
TIMELINE_SERIALIZATION_INVALID
TIMELINE_BASELINE_CONFLICT
TIMELINE_STALE_SESSION
TIMELINE_EXPORT_FAILED
TIMELINE_CANCELED
```

剩余关闭输入：

- `corrected`/`spoken` 缺失或 revision 不一致时的显示/阻断行为；
- JSON speaker 字段的稳定 ID/显示名投影，以及 WebVTT/SRT profile 的 ID/version、`subtitle_text_layer`（`corrected` 或 `spoken`）、所选 revision 缺失/不一致时的阻断行为、默认 profile、有前缀/无前缀策略、前缀模板和转义规则；

- 项目自有 SRT 兼容 profile 的换行、cue 编号、空行和文本换行规则；
- 显示名变化时重建哪些派生导出，哪些时间数据保持 current。

不得以某个本机播放器的偶然容忍行为代替明确 profile。

关闭证据：以上显示/导出 profile 字段全部固定为版本化机器可校验值，包含缺失/不一致阻断、speaker 投影、`subtitle_text_layer`、前缀/转义、VTT/SRT 时间与换行规则、显示名变化影响；冻结夹具覆盖边界，验证步骤、判定、证据路径和负责人完整。

## 8. 验收标准

- 完整章节播放时按 ScriptUnit 自动高亮；
- 阅读器默认显示 corrected，可查看 spoken，两者均保留来源 revision；
- 点击文本和拖动音频都能稳定定位另一侧；
- JSON、WebVTT、SRT 从同一 timeline revision 确定性导出；
- 任一条目可追溯到 assembly、Clip、AudioClip revision 和 ScriptUnit；
- 时间范围合法且不越过章节时长；
- assembly 更新只使对应章节 timeline/字幕过期；
- 历史 timeline 和导出不覆盖；
- 项目切换后旧播放、旧事件和旧 URL 不进入新项目；
- 任何时间调整返回 M6 重新装配，不创建 timeline override；
- MVP 不依赖字/词级对齐或可编辑时间轴。

## 9. 对下游的稳定交付

M7 向 M8 交付：

- immutable `ChapterTimeline` revision 和完整 JSON artifact；
- TimelineEntry 的稳定 ID、ScriptUnit/speaker/display text、Clip/audio 来源和整数毫秒范围；
- WebVTT/SRT 派生 artifact、serializer/profile version 和 hash；
- timeline → assembly → clip → ScriptUnit 的完整依赖链；
- 章节 duration、stale/missing 状态和精确 chapter selector；
- 受控播放 URL 能力，不含绝对路径。

不得向下游暴露播放器局部状态、DOM、绝对路径或把 VTT/SRT 当作项目真值。
