## 2. 范围与非目标

### 2.1 M6 范围

- 只选择当前、存在且最终 QA 结论为 `approved` 的 AudioClip revision；
- 按 ScriptUnit 正式顺序生成不可变的章节装配计划；
- 应用版本化的停顿、Clip 增益、短淡入淡出和 MVP 基础响度策略；
- 通过可替换 `AudioProcessorPort` 生成章节音频；
- 保存输入清单、处理策略、输出规格、哈希、时长和 Clip 时间范围；
- 从章节时间点反查 `clipRefId`、`audioArtifactId` 和 `scriptUnitId`；
- 支持替换一个活动片段后只使对应章节过期并重建该章节；
- 提供章节试听、缺失项提示、历史 revision 和人工参数调整入口。

### 2.2 非目标

- 不实现自动 BGM、SFX、环境音或复杂多轨混音；
- 不实现复杂 EQ、Compressor、De-esser、Noise Gate 或母带工作站；
- 不生成全书最终发布容器或发布元数据；
- 不修改 ScriptUnit、spoken、VoiceProfile、AudioClip 或 QAResult；
- 不允许未批准、`stale`、`missing`、`rejected` 或损坏片段进入正式装配；
- 不根据文件名排序，不把可变文件路径作为长期引用；
- 不覆盖旧章节音频、旧清单或旧时间线；
- 不在 Renderer、Preload 或 Main 中执行音频处理。

## 3. 小模型执行协议

每次只领取一个任务 ID。开始前必须读取根 `AGENTS.md`、本文件第 1～6 节、任务卡列出的输入和任务开始时的 `git status --short`。

执行规则：

- 核对全部前置任务和 Decision Gate 的书面关闭证据；
- 只修改任务卡“允许写入”列出的路径；
- 先补失败测试或冻结夹具，再写最小实现；
- 测试从目标包构建后的 `dist` 导入，沿用仓库现有 `test/*.test.mjs` 约定；
- 只使用现有依赖；新增依赖、可执行文件或网络端点必须由对应门禁批准；
- 不修改 `项目计划.md`、`docs/spec/`、ADR、`docs/ideas/`、其他里程碑规格或根待办；
- 不执行 `git add`、`git commit`、`git reset`、批量格式化或清理既有文件；
- Mock、静态检查或文档完成不得表述为真实音频处理已通过。

任务结束前运行：

```bash
git diff --check
git status --short
```

交接格式：

```text
任务：M6-XX
结果：complete | blocked | failed | not_applicable
修改文件：逐项列出
验证：命令、退出码和覆盖的断言
未验证：真实处理器、桌面交互或目标平台项
既有改动：是否保持不变
阻塞：Decision Gate、缺失契约或原始错误文本
```

## 4. 公共不变量

- `ChapterAssembly` 只引用不可变 artifact/revision ID，不保存可变绝对路径；
- 输入 Clip 必须同时满足：存在、`current`、最终 QA `approved`、属于当前 ScriptUnit revision；
- ScriptUnit 顺序来自正式剧本，不得由文件名、创建时间或数据库偶然顺序推断；
- `clipRefs` 的 `order` 唯一、连续，时间范围非负、单调且不越过章节时长；
- 公共时间范围使用整数毫秒半开区间 `[startMs, endMs)`；处理器内部更精确的单位必须在边界统一换算并记录舍入策略版本；
- 停顿、增益、淡入淡出和响度策略必须版本化并进入输入指纹；
- 相同输入 revision、顺序、策略、处理器版本和参数产生相同输入指纹；
- 处理结果先写任务专属 `tmp/<task-id>/`，完整校验后才提交正式 revision；
- 取消、失败或 Core 重启不得提交半成品，也不得覆盖历史 revision；
- 单片段变化只传播到实际引用该片段的章节 assembly 及其下游；
- 仅修改页面显示状态或审核备注不得使章节音频过期；
- 领域、workflow 和契约不得包含 FFmpeg 命令行、外部 API 私有 DTO 或 Renderer 状态；
- Renderer 只能通过受控 artifact URL 播放，不接收正式文件绝对路径；
- 未关闭的门禁只能产生 `blocked` 交接，不能用默认值绕过。

统一错误码至少包括：

```text
CHAPTER_ASSEMBLY_INPUT_INCOMPLETE
CHAPTER_ASSEMBLY_INPUT_NOT_APPROVED
CHAPTER_ASSEMBLY_INPUT_STALE
CHAPTER_ASSEMBLY_ORDER_INVALID
CHAPTER_ASSEMBLY_FORMAT_MISMATCH
CHAPTER_ASSEMBLY_POLICY_INVALID
CHAPTER_ASSEMBLY_PROCESSOR_UNAVAILABLE
CHAPTER_ASSEMBLY_OUTPUT_INVALID
CHAPTER_ASSEMBLY_STALE_SESSION
CHAPTER_ASSEMBLY_CANCELED
```

新增错误码必须先进入契约测试，禁止在适配器中创建同义错误。

## 8. 验收标准

- 一个全部输入已批准的章节可以生成完整可播放音频；
- 任一章节时间点可以反查 Clip、AudioClip revision 和 ScriptUnit；
- 缺失、未批准、拒绝、过期或损坏输入阻断正式装配；
- 停顿、增益、淡化、响度和处理器参数有版本并进入输入指纹；
- 单片段替换只使引用章节及其时间轴/发布下游过期；
- 失败、取消和重启不提交半成品；
- 历史 assembly、音频和清单不被覆盖；
- Renderer 不获得绝对路径，Main/Preload 不执行音频处理；
- MVP 不依赖 BGM/SFX、多轨或复杂母带能力。

## 9. 对下游的稳定交付

M6 向 M7/M8 交付：

- immutable `ChapterAssembly` revision；
- 有序 `AudioClipRef[]`，包含稳定 `clipRefId`、`scriptUnitId`、`audioArtifactId/revisionId`；
- 整数毫秒 `[startMs,endMs)`、总时长和精确时间换算策略版本；
- 章节音频 Artifact、输出规格、文件 hash 和受控 playback URL 能力；
- processing policy/processor/version/parameters 和完整 input fingerprint；
- 缺失/阻断 issue、review 状态、历史 revision 和 stale cause；
- 单片段变化对应的精确 chapter selector。

不得向下游暴露命令行、外部 API 私有 DTO、临时目录、绝对路径、凭据或未提交输出。
