# 阶段 90：MVP 联调与验收

## 目标

使用真实授权样章走通完整制作流程，汇总质量、时间、成本和人工工作量，为下一轮产品范围提供依据。

## 工作步骤

1. 选择约 30 分钟、角色规模适合首轮验证的授权样章。
2. 从项目创建开始走通阶段 00～11。
3. 完成文本、角色、发音、音频和导出的人工审核。
4. 处理问题片段并验证局部调整与重新生成。
5. 验证项目重开、中断恢复和工程重新导入。
6. 分别修改一处文本、发音和角色声音，观察后续影响范围。
7. 汇总质量、耗时、成本、稳定性和人工操作数据。
8. 根据实际数据确定下一轮产品范围和阶段优先级。

## 阶段结果

形成完整样章、验证记录、指标汇总和下一轮产品决策。
