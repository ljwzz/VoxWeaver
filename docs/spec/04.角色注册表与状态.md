# 阶段 04：角色注册表与状态

## 目标

建立全项目统一的角色档案，让人物名称、别名、长期阶段和剧本说话人保持一致。

## 工作步骤

1. 汇集人物提及、称谓、别名和说话人候选。
2. 归并同一角色并区分同名人物。
3. 设置角色重要度、基础信息和长期阶段。
4. 把确认后的角色关系回填到剧本单元。
5. 审核归并证据、冲突和有效范围。
6. 保存角色档案版本与合并、拆分和调整历史。

## 阶段结果

形成稳定的角色档案、别名关系、角色阶段和说话人映射。
