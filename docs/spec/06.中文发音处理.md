# 阶段 06：中文发音处理

## 目标

把剧本文本整理为符合目标朗读方式的可审核文本，统一项目中的专名、多音字、数字和单位表达。

## 工作步骤

1. 为每个剧本单元生成朗读文本。
2. 处理数字、日期、单位、英文和缩写的朗读表达。
3. 应用项目词典、角色词典和已确认规则。
4. 为多音字、生僻字和上下文读法提供候选。
5. 对照剧本文本审核并锁定关键读法。
6. 保存朗读文本版本和词典命中记录。

## 阶段结果

形成逐单元可审核的朗读文本、项目发音词典和人工确认记录。
