# 阶段 10：时间轴与同步阅读

状态：`planned`
实现审计：`unverified`
前置阶段：[09 章节合成与基础后期](./09.章节合成与基础后期.md)

## 1. 目标

基于章节 Clip 时间轴生成稳定的文本时间轴、字幕文件和最小同步阅读器，实现音频位置与 ScriptUnit 文本双向跳转。

## 2. 范围

- `AudioTimeline + TextTimeline`；
- ScriptUnit 的 start/end 时间；
- JSON、WebVTT、SRT 导出；
- 章节播放、跳转和文本同步高亮；
- 点击文本跳转音频、点击时间跳转文本；
- 时间轴 revision、校验和下游依赖。

## 3. 非目标

- 不在 MVP 实现逐字强制对齐；
- 不实现移动端、在线协作和云端播放器；
- 角色头像、书签、笔记和复杂主题未纳入当前正式范围；只有逐项批准并先更新主计划后才可另行规划；
- 不重新解释剧本或修改章节音频。

## 4. 数据模型

```ts
interface TimelineEntry {
  timelineEntryId: string;
  chapterId: string;
  scriptUnitId: string;
  speakerId?: string;
  text: string;
  startMs: number;
  endMs: number;
  sourceClipRefId: string;
}

interface ChapterTimeline {
  timelineId: string;
  chapterAssemblyRevisionId: string;
  entries: TimelineEntry[];
  durationMs: number;
}
```

时间范围必须单调、非负、不越过章节时长；同一 ScriptUnit 与 AudioClip 的映射必须可反查。

## 5. 格式输出

- JSON 是项目内完整契约，保留稳定 ID、角色和来源；
- WebVTT、SRT 是兼容输出，只表达其格式可承载的字段；
- 不得把 WebVTT/SRT 再导入作为项目唯一真值；
- WebVTT/SRT 的字幕文本层由 M7-D01 关闭记录中的版本化导出 profile 的 `subtitle_text_layer` 决定；字段缺失或所选 revision 不可用时必须按该 profile 明确阻断，不得默认猜测；
- 时间舍入必须定义统一规则并测试边界。

WebVTT 的语法与媒体类型以 W3C 规范为准：
https://www.w3.org/TR/webvtt1/

## 6. 阅读器最小能力

- 播放、暂停、倍速和拖动；
- 章节切换；
- 当前 ScriptUnit 文本高亮；
- 当前角色显示；
- 点击文本跳转音频；
- 音频进度变化定位文本；
- stale、缺失或部分生成状态提示。

书签、笔记、字体、夜间模式、Scene 信息和头像未纳入当前正式范围；只有逐项批准并先更新主计划后才可另行规划，且当前不得阻塞 M7。

## 7. 版本和过期影响

- ChapterAssembly revision 变化使对应时间轴和字幕过期；
- 仅显示样式变化不使数据时间轴过期；
- speaker 显示名称变化可以重新导出显示数据，但不改变音频时间；
- 章节顺序变化只使全书目录和发布清单过期，单章时间轴保持有效；
- 旧时间轴和字幕继续保留并标记来源。

## 8. 早期实现迁移

检查旧实现是否：

- 用音频文件名而非 Clip/ScriptUnit ID 关联；
- 使用浮点秒导致累计误差且无统一舍入；
- 文本修改后仍显示旧时间轴为当前；
- WebVTT/SRT 被当作唯一数据源；
- 无法从音频时间反查 ScriptUnit；
- 项目切换时播放器仍使用旧项目状态。

播放器组件可按接口 `adapt`；无法追溯 assembly revision 的旧字幕作为历史导出保留。

## 9. 测试要求

- 时间范围单调、合法且不超出章节；
- JSON/WebVTT/SRT 序列化；
- 时间舍入和章节边界；
- 文本点击和进度回调双向定位；
- 章节切换和项目切换隔离；
- assembly 更新只使对应时间轴过期；
- stale 或缺失状态正确显示。

## 10. 验收标准

- 完整章节播放时文本按 ScriptUnit 自动高亮；
- 文本和音频可双向跳转；
- JSON、WebVTT 和 SRT 可导出；
- 任一时间条目可追溯到 assembly、Clip 和 ScriptUnit；
- 时间轴更新不覆盖旧版本；
- 页面不会跨项目串用播放状态。
