# 阶段 05：声音系统与音色分配

## 目标

为角色建立可试听、可比较、可调整的声音配置，并保持跨章节的一致体验。

## 工作步骤

1. 登记声音素材、来源、授权范围和质量信息。
2. 创建声音配置并使用真实项目文本试听。
3. 比较不同声音、参数和表达效果。
4. 为角色及其长期阶段绑定声音配置。
5. 维护普通角色可选声音集合。
6. 检查同一场景中的声音区分度并调整分配。
7. 激活确认后的声音配置。

## 阶段结果

形成已审核的角色声音配置、分配关系和试听记录。
