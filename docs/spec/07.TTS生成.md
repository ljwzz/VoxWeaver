# 阶段 07：TTS 生成

## 目标

按剧本单元生成独立语音片段，让用户查看进度、试听版本并完成局部调整。

## 工作步骤

1. 选择已审核的剧本单元和生成范围。
2. 组合朗读文本、角色声音和表达状态。
3. 逐单元生成语音并展示任务进度。
4. 试听同一单元的不同音频版本。
5. 继续、取消、重试或局部重新生成任务。
6. 保存音频片段及其输入和生成记录。
7. 将当前音频版本提交到质量审核。

## 阶段结果

形成可追溯、可独立替换的语音片段和生成历史。
