# 阶段 01：小说导入与文件预处理

## 目标

进入项目后，把已经保存的小说源文件副本整理为结构清晰、来源可追溯、便于后续处理的项目文本。

## 与新建项目的边界

- 本阶段只在阶段 00 已成功创建项目并保存项目源文件副本后开始。
- 本阶段读取项目内的源文件副本，不再依赖用户最初选择的项目外部文件。
- 格式识别、编码确认、文本提取和转换文件保存只在正式项目工作台执行，不得提前并入新建项目流程。
- 本阶段的识别或转换失败只阻止进入后续文本处理，不得使阶段 00 已创建成功的项目或源文件副本失效。

## 工作步骤

1. 在项目内加载已经保存的源文件副本。
2. 识别并确认文件格式、编码和基础书目信息。
3. 提取文本并统一排版、空白和基础字符表达。
4. 识别卷、章节、场景和原文位置。
5. 预览识别结果并调整章节、标题和边界。
6. 生成导入报告和后续步骤可用的小说结构。

## 阶段结果

形成已确认的小说结构、章节顺序、场景边界和来源定位。

## 当前工程契约

### SourceAsset 与编码

- 仅读取 manifest 绑定的项目内 TXT SourceAsset；每次读取重新校验普通文件、路径 containment、byte length 和 SHA-256，不再次选择外部文件。
- UTF-8/UTF-16LE/UTF-16BE BOM 自动确认；无 BOM 时只自动确认严格 UTF-8。
- 其他输入必须手动选择 GBK、GB18030、Big5、UTF-16LE 或 UTF-16BE。选择绑定当前 SourceAsset hash；UTF-32、空文本、NUL 和无效字节序列直接拒绝。

### 任务与产物

- 导入指纹由源 hash、确认编码和处理器版本生成；同一有效输入复用现有 pending/running/succeeded 任务。
- 任务状态为 `pending/running/succeeded/failed/canceled`，提供进度事件、取消、重试和 Core 中断后的 retryable 恢复。
- 失败不得修改 SourceAsset 或最后一个有效 revision；成功后才原子发布 UTF-8 文本、复核快照和 artifact/任务记录。

### 章节复核

- 复核快照包含章节候选、章节、UTF-8 byte 边界、覆盖率、未覆盖范围、规范化提案、diff 和 revision history。
- 边界调整、未覆盖范围分类、规范化决策、局部重跑和阶段确认都必须基于当前 baseline revision，并先持久化 stale 影响预览；基线变化时拒绝提交。
- 每次应用复核命令都创建新的小说导入 revision 和 baseline，并将上一 producer revision 标记为已取代；受影响的下游依赖写入指向新 revision 的 stale cause。局部重跑重新读取选定 UTF-8 范围并替换对应候选、章节和覆盖区段。
- 章节正文只通过 UTF-8 byte range 读取；每次最多 256 KiB，范围必须落在 UTF-8 字符边界，且 artifact 路径不得越出项目或包含符号链接。
- 覆盖范围仍未完成或规范化提案仍待决时，不能确认阶段 01。确认后阶段 02 进入“前置已满足但能力尚未实现”的门禁状态。
