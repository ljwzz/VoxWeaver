# 阶段 01：小说导入与文件预处理

## 目标

把小说文件整理为结构清晰、来源可追溯、便于后续处理的项目文本。

## 工作步骤

1. 选择小说文件并登记来源与授权信息。
2. 识别文件格式、编码和基础书目信息。
3. 提取文本并统一排版、空白和基础字符表达。
4. 识别卷、章节、场景和原文位置。
5. 预览识别结果并调整章节、标题和边界。
6. 生成导入报告和后续步骤可用的小说结构。

## 阶段结果

形成已确认的小说结构、章节顺序、场景边界和来源定位。
