# 阶段 02：文本校对

## 目标

帮助用户发现并处理文本问题，形成可对照、可审核、可追溯的校对版本。

## 工作步骤

1. 扫描错字、标点、重复内容和名称一致性候选。
2. 按章节、类型和置信度整理候选。
3. 对照原文、修改建议和判断依据。
4. 接受建议、保留原文或手动编辑。
5. 批量确认同类问题并复核高影响修改。
6. 保存校对版本并展示后续影响范围。

## 阶段结果

形成经过用户确认的校对文本和完整修改记录。
