# 阶段 11：工程导入导出与发布

## 目标

让用户保存、恢复和迁移工程配置，并生成带有完整来源与导出记录的章节或全书成品。

## 工作步骤

1. 选择工程配置、成品或两者组合的导出目标。
2. 根据素材授权选择配置、元数据和资产。
3. 生成工程包并完成版本、结构和完整性校验。
4. 在新项目中导入工程包并重新绑定小说与声音素材。
5. 检查章节、审核状态、授权信息和成品完整性。
6. 选择成品格式、章节顺序和发布元数据。
7. 生成文件清单并保存导出快照。

## 阶段结果

形成可恢复的工程包、可交付的音频成品和可追溯的导出记录。
