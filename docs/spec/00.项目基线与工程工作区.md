# 阶段 00：项目基线与工程工作区

## 目标

建立贯穿完整制作流程的本地项目工作区，让用户集中管理素材、处理步骤、版本、任务和审核状态。

## 工作步骤

1. 创建、打开和切换项目。
2. 设置项目位置并登记小说、声音和其他素材。
3. 展示完整制作流程、当前步骤和任务进度。
4. 保存各步骤的处理结果、版本关系和审核记录。
5. 展示局部修改对后续结果的影响。
6. 维护项目设置和所需服务连接。
7. 恢复中断任务并继续上次工作。

## 新建项目页面

### 页面输入

新建项目页面只包含以下两个业务输入：

| 输入 | 要求 |
|---|---|
| 项目存放文件夹 | 必选、可重新选择，用于创建本次项目工作目录 |
| 源文件 | 必选、可重新选择，只登记用户选择的文件路径和文件名 |

### “下一步”创建事务

点击“下一步”后只执行项目创建和源文件复制：

1. 校验项目存放文件夹和源文件均已选择且当前可访问。
2. 创建本次项目工作目录，且不得覆盖已有项目或同名目录中的有效内容。
3. 以只读方式打开外部源文件，将原始字节复制为项目源文件副本（SourceAsset）。
4. 校验项目源文件副本与复制输入的内容一致，并登记其来源关系和完整性信息。
5. 持久化项目创建成功状态。
6. 只有以上操作全部成功后，才进入项目页面。

### 状态、失败与重试

- 项目存放文件夹或源文件缺失时，“下一步”不可执行。
- 创建或复制过程中锁定两个输入并禁用重复提交。
- 项目目录创建、源文件读取、复制、完整性校验或项目状态持久化任一步失败时，停留在当前页面，不得进入项目。
- 失败时保留仍然有效的两个选择，并说明失败阶段和可执行的重试方式。
- 未完成的项目目录不得登记为可打开项目；重试不得覆盖已有的有效源文件副本。

## 项目文件不变量

- 用户选择的项目外部源文件只作为导入输入；应用不得修改、覆盖、移动或删除该文件。
- 项目源文件副本按原始字节保存，属于不可变原始素材；应用不得就地修改、覆盖或删除其内容。
- 后续格式识别、文本转换和其他处理只能读取项目源文件副本，并将结果保存为独立派生产物。
- 项目创建成功后的打开和后续处理不得依赖项目外部源文件继续存在。
- 这里的“不可变”指应用层禁止写入、覆盖和删除；不得承诺用户无法通过系统文件工具手动修改项目文件。

## 阶段结果

形成稳定的项目上下文和已校验的项目源文件副本，为后续步骤提供统一入口、状态和历史记录。
