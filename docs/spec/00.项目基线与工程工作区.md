# 阶段 00：项目基线与工程工作区

## 目标

建立贯穿完整制作流程的本地项目工作区，让用户集中管理素材、处理步骤、版本、任务和审核状态。

## 工作步骤

1. 创建、打开和切换项目。
2. 设置项目位置并登记小说、声音和其他素材。
3. 展示完整制作流程、当前步骤和任务进度。
4. 保存各步骤的处理结果、版本关系和审核记录。
5. 展示局部修改对后续结果的影响。
6. 维护项目设置和所需服务连接。
7. 恢复中断任务并继续上次工作。

## 阶段结果

形成稳定的项目上下文，为后续步骤提供统一入口、状态和历史记录。
