# 阶段 00：项目基线与工程工作区

## 目标

建立贯穿完整制作流程的本地项目工作区，让用户集中管理素材、处理步骤、版本、任务和审核状态。

## 工作步骤

1. 创建、打开和切换项目。
2. 设置项目位置并登记小说、声音和其他素材。
3. 展示完整制作流程、当前步骤和任务进度。
4. 保存各步骤的处理结果、版本关系和审核记录。
5. 展示局部修改对后续结果的影响。
6. 维护项目设置和所需服务连接。
7. 恢复中断任务并继续上次工作。

## 新建项目页面

### 页面输入

新建项目页面只包含以下三个业务输入：

| 输入 | 要求 |
|---|---|
| 项目名称 | 必填、可编辑，去除首尾空白后不能为空或包含控制字符；后续工作台以此名称标识项目，不从源文件名推断 |
| 项目存放文件夹 | 必选、可重新选择；所选空文件夹本身作为项目根目录，不再创建名称派生的子目录 |
| 源文件 | 必选、可重新选择；当前仅允许选择 `.txt` 文件，只登记用户选择的文件路径和文件名 |

### “创建并打开项目”事务

点击“创建并打开项目”后只执行项目创建和源文件复制：

1. 校验项目名称有效，且项目存放文件夹和 `.txt` 源文件均已选择并可访问。
2. 校验项目文件夹为空、可写且不是符号链接，不得覆盖或合并已有内容。
3. 以只读方式打开外部源文件，将原始字节复制为项目源文件副本（SourceAsset）。
4. 校验项目源文件副本与复制输入的内容一致，并登记其来源关系和完整性信息。
5. 持久化项目创建成功状态。
6. 只有以上操作全部成功后，才进入项目页面。

### 状态、失败与重试

- 项目名称、项目存放文件夹或源文件缺失时，“创建并打开项目”不可执行。
- 创建或复制过程中锁定三个输入并禁用重复提交。
- 项目目录创建、源文件读取、复制、完整性校验或项目状态持久化任一步失败时，停留在当前页面，不得进入项目。
- 失败时保留仍然有效的名称和两个选择，并说明失败阶段和可执行的重试方式。
- 未完成的项目目录不得登记为可打开项目；重试不得覆盖已有的有效源文件副本。

## 启动窗口、最近项目与多开

- 启动窗口固定为 700×450，并在屏幕中居中显示；尺寸由代码常量统一维护。
- 启动窗口使用 macOS 原生窗口控制按钮，不在页面中模拟红绿灯。
- 启动窗口与项目窗口相互独立；项目打开后启动窗口隐藏，可通过“文件 → 打开项目启动器”重新显示并继续创建或打开其他项目。每个不同项目在独立工作台窗口中打开。
- 同一项目已经打开时，再次打开只聚焦现有工作台，不创建第二个写入窗口。
- 最近项目显示全部记录，并按最后打开时间从新到旧排列；记录项目名称、目录和最后打开时间，移除最近记录不得删除项目目录或关闭工作台。
- 最近项目目录缺失或项目标识无效时显示对应状态，并禁止直接打开。

## 项目文件不变量

- 用户选择的项目外部源文件只作为导入输入；应用不得修改、覆盖、移动或删除该文件。
- 项目源文件副本按原始字节保存，属于不可变原始素材；应用不得就地修改、覆盖或删除其内容。
- 后续格式识别、文本转换和其他处理只能读取项目源文件副本，并将结果保存为独立派生产物。
- 项目创建成功后的打开和后续处理不得依赖项目外部源文件继续存在。
- 这里的“不可变”指应用层禁止写入、覆盖和删除；不得承诺用户无法通过系统文件工具手动修改项目文件。

## 阶段结果

形成稳定的项目上下文和已校验的项目源文件副本，为后续步骤提供统一入口、状态和历史记录。

## 当前工程契约

- manifest 使用 `schemaVersion: 1`、`layoutVersion: 2`，保留用户选择的空目录作为项目根目录，并记录 `updatedAt`。
- 项目状态库固定为 `state/project.sqlite`；项目内包含版本化 artifact、SourceAsset、task、stage run、review decision、依赖和 stale cause 记录。
- layout v1 打开时先返回显式确认；确认令牌绑定启动窗口、项目和文件身份。迁移先备份 manifest/SQLite，再通过 journal、临时数据库和原子替换完成；任一迁移阶段失败时恢复 v1 文件。
- 每个项目写会话持有 `state/locks/write-lock.json`。活跃锁拒绝打开，确定失效的锁需要显式确认；Core 崩溃后仅允许 Main 以完全相同的 app/project session 身份接管。
- `/project` 是正式工作台父布局。Main 按项目 ID 和规范化根目录维护独立窗口，Core 通过 `ProjectSessionRegistry` 同时管理不同项目。
- Renderer 不能提交项目路径、项目 ID 或 session ID。Main 根据已登记的 `webContents` 注入可信会话，Preload 只暴露具名命名空间方法。
- `/pages/*` 属于开发预览；生产路由和正式工作台不得依赖 demo、mock 或 fixture。

完整工程备份/恢复、Provider 和后续阶段写入不属于阶段 00 当前实现范围。
