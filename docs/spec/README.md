# VoxWeaver 步骤规格索引

本目录记录桌面页面的通用实现要求，以及各业务阶段的目标、输入、处理、结果和前后关联，作为界面设计、编码和验收的正式规格入口。

编码不得只还原静态设计稿。每个页面都必须同时落实真实数据来源、操作状态、持久化结果、错误恢复和页面跳转门禁；未明确的业务规则应先补充规格，不得在实现时自行推断。

## 通用规格

- [桌面页面与交互编码要求](./通用页面与交互编码要求.md)：适用于已经确认和后续新增的全部桌面页面。
