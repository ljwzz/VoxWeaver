# 阶段 08：音频 QA

## 目标

结合自动检查和人工试听识别音频问题，并把每个问题带回对应的文本、发音、声音或生成步骤。

## 工作步骤

1. 接收音频片段及其实际朗读文本。
2. 生成回听文本并检查音频完整性、响度、静音和截断情况。
3. 对照朗读文本、回听结果和音频指标。
4. 在剧本行和质量审核页展示问题位置与证据。
5. 确认通过，或返回对应步骤完成调整和重新生成。
6. 保存检查结果、人工决定和历史版本。

## 阶段结果

形成逐片段的质量结论、问题证据、处理去向和审核历史。
