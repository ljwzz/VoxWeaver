# 阶段 03：小说剧本化

## 目标

把校对文本整理为可编辑、可审核、可配音的结构化剧本。

## 工作步骤

1. 按表达和配音需要切分剧本单元。
2. 区分旁白、对白、内心表达和其他叙述类型。
3. 提取说话人、情绪、身体状态和表达方式候选。
4. 结合角色档案持续更新说话人解析。
5. 对照原文审核单元顺序、文本、类型和候选信息。
6. 保存剧本版本和历史调整记录。

## 阶段结果

形成覆盖完整文本的剧本单元、表达类型和说话人候选。
