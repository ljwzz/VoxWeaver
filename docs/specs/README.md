# 技术规格

本目录保存已经细化到可评审程度的技术规格。规格状态含义：

- `draft`：设计草案，不构成实施批准；
- `accepted`：已经由对应 ADR 和项目计划确认，可以作为实施与验收依据；
- `superseded`：已被后续规格替代，仅保留历史信息。

规格负责描述组件、进程、接口、数据、失败恢复、安全和验收要求，不替代：

- `项目计划.md` 的产品范围；
- `plan/` 的阶段顺序；
- `docs/adr/` 的技术选型批准和取舍记录；
- `docs/schemas/` 的机器可校验契约。
