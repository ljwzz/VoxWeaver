## 1. 纵向链路

```text
M0 项目基础设施
→ M1 小说导入
→ M2 文本 AI 处理
→ M3 角色系统
→ M4 语音生成
→ M5 音频 QA
→ M6 章节合成
→ M7 同步阅读
→ M8 工程导入导出
```

里程碑表示可验收的纵向能力，不表示所有任务只能串行。只有共享 schema、index、package.json、锁文件、路由或同一写入文件的任务必须串行。

### 3.1 决策基线

项目负责人于 2026-08-08 冻结全部决策项的当前已选策略，并于 2026-08-09 追加确认 M1-D05 的方案 A。阶段 00 集成验证已关闭 M1-G00；策略冻结仍不等于补齐外部执行输入，M1-D05 的预算数值未齐，因而保持 `open`。各行状态与剩余输入以对应架构或里程碑规格内的 Gate 为权威来源。

| 里程碑 | 已冻结的主要分支 | 仍需独立补齐的执行输入 |
|---|---|---|
| ARCH | 单一正式平台；单一打包工具；软配额且正式 revision 不自动删除 | OS/最低版本/CPU/安装包；`engines`/`.nvmrc`/ADR 0002 的 Node 支持范围解释与 Electron 内置 Node/`node:sqlite` 兼容证据；打包/签名/更新 ADR 与发布输入；配额、保护线、保留期与恢复窗口 |
| M1 | Scene/Segment 移交 M2；只做 TXT；复制输入；Markdown 后续 | TXT 编码白名单、byte range/ID 细则、TXT 资源预算、私有基准证据 |
| M2 | M2 建 Scene/Segment；连续 slices；SAFE 自动应用；精确 `scriptUnitIds` | LLM Provider/ADR/live profile；SAFE policy；说话人阈值和校准样章 |
| M3 | 核心标签加扩展；自动质量检查加人工试听；精确影响展开 | rights/quality 字段；检查器与区分度实现、版本、预算和测试命令 |

## 4. 完成传播

- 上游里程碑完成只证明其稳定输出，不自动证明下游已实现。
- 上游 revision 变化时，下游只按依赖 selector 标记实际交集为 stale。
- 里程碑验收失败必须返回具体任务，不在验收卡修改 expected 或降低阈值。
- M8 完成后仍需使用阶段 90 的合法样章执行一次 M0～M8 纵向审计。
