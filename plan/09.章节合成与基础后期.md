# 阶段 09：章节合成与基础后期

状态：`planned`
实现审计：`unverified`
前置阶段：[08 音频 QA](./08.音频QA.md)

## 1. 目标

把审核通过的 AudioClip 按剧本顺序装配为章节音频，保留 Clip 时间线，并执行 MVP 所需的停顿、淡化和基础响度处理。

## 2. 范围

- AudioClip 引用和顺序；
- Clip 间距、停顿和必要的短淡化；
- 基础响度检查与统一；
- 章节 WAV 或确定的中间格式；
- 片段到章节时间轴；
- 章节装配 revision、输入清单和输出哈希；
- 单章重建和片段替换。

## 3. 非目标

MVP 不包含：

- 自动 BGM、SFX 和环境音混音；
- 复杂 EQ、Compressor、De-esser、Noise Gate 等母带流程；
- 完全自动的场景音效决策；
- 全书最终容器和发布元数据，属于阶段 11。

这些能力属于 MVP 稳定后的第二阶段扩展。

## 4. Timeline 与 Clip

```ts
interface AudioClipRef {
  clipRefId: string;
  scriptUnitId: string;
  audioArtifactId: string;
  order: number;
  startMs: number;
  endMs: number;
  gainDb?: number;
  fadeInMs?: number;
  fadeOutMs?: number;
  pauseAfterMs?: number;
}

interface ChapterAssembly {
  assemblyId: string;
  chapterId: string;
  clipRefs: AudioClipRef[];
  processingPolicyVersion: string;
  outputArtifactId: string;
}
```

时间和范围字段使用整数毫秒或经 ADR 确认的无歧义单位，不使用混合浮点单位。

## 5. 装配流程

```text
选择当前 approved AudioClip
→ 校验 ScriptUnit 顺序和完整性
→ 应用停顿和 Clip 级设置
→ 基础响度/峰值处理
→ 章节拼接
→ 生成章节音频、Clip 时间轴和清单
→ 验证可播放、时长和反向定位
```

FFmpeg 提供 concat filter/demuxer 等拼接方式，可作为适配器候选；具体命令和是否重编码由音频格式 ADR 决定：

https://www.ffmpeg.org/faq.html

## 6. 页面和审核

- 章节波形和 Clip 时间线；
- 试听单 Clip、相邻过渡和完整章节；
- 调整停顿、增益和短淡化；
- 替换某一 ScriptUnit 的活动 AudioClip；
- 显示缺失、拒绝、过期和未审核片段；
- 只重建当前章节；
- 比较历史 assembly revision。

## 7. 版本和过期影响

- ScriptUnit 顺序、活动 AudioClip、停顿或处理策略变化使对应章节 assembly 过期；
- 单一片段变化不使其他章节过期；
- 章节标题或全书顺序变化不使章节音频过期，除非章节音频包含朗读标题；
- assembly 过期使依赖它的时间轴和发布导出过期；
- 旧章节音频和清单保留；
- 仅页面显示设置变化不传播到音频。

## 8. 早期实现迁移

检查旧实现是否：

- 通过文件名排序拼接；
- 直接引用可变音频路径；
- 混入未审核或过期片段；
- 无 Clip 到 ScriptUnit 的反向定位；
- 修改一句就重建全书；
- 后期参数无版本；
- 章节输出覆盖旧文件。

可复用的 FFmpeg/音频处理代码应包装为版本化处理器；缺少输入清单的旧章节音频作为历史外部资产保留。

## 9. 测试要求

- ScriptUnit 顺序与 Clip 顺序一致；
- 未批准、缺失和 stale 片段阻断当前正式装配；
- 停顿、淡化、增益和时长计算；
- 输出可播放、无损坏且时间轴范围有效；
- 从任意时间点可反查 Clip 和 ScriptUnit；
- 替换一个片段只重建一个章节；
- 中断不会提交半成品章节。

## 10. 验收标准

- 可以播放完整章节；
- 对白顺序正确，角色音频引用正确；
- 基础音量和过渡通过样章人工审核；
- 任一章节可独立重建；
- 章节音频可反查全部输入片段；
- 旧版本不被覆盖；
- MVP 不依赖复杂 BGM/SFX 或母带系统。

## 11. 待决策事项

- 中间音频格式、采样率、位深和声道；
- 响度和峰值目标；
- 停顿规则和人工覆盖优先级；
- 是否在 MVP 支持多轨时间线；
- FFmpeg 调用方式和沙箱边界；
- 第二阶段复杂后期的插件接口。
