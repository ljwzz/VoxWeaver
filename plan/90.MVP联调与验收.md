# 阶段 90：MVP 联调与验收

状态：`planned`
实现审计：`unverified`

## 1. 目标

完成一个合法授权、约 30 分钟、角色不超过 5 个的样章闭环，以真实数据评估人工修改率、重生成率、专有名词错误率、处理时间、资源成本和是否继续扩展。

该里程碑不是独立业务阶段，而是贯穿 00～11 的纵向验收。

## 2. MVP 范围

```text
项目创建
→ TXT/EPUB 导入和章节识别
→ 文本校对
→ 剧本和角色解析
→ 角色音色配置
→ 中文发音
→ ScriptUnit 级 TTS
→ ASR/音频 QA
→ 章节合成
→ JSON/WebVTT/SRT 时间轴
→ 工程配置和成品导出
```

MVP 暂不包含：

- 自动 BGM/SFX 和复杂混音；
- 大规模音色微调管理；
- 移动端；
- 在线协作、多用户和云端大规模调度；
- 模型、声音或素材市场；
- DOCX、PDF、MOBI/AZW 等扩展格式。

| 里程碑 | 对应阶段 | 完成标志 |

| M3 角色系统 | 04、05 | 核心角色稳定，Scene 内普通角色可区分 |

## 4. 样章选择

样章必须：

- 文本、音色和预期发布方式具有明确许可；
- 包含旁白、2～4 个角色、对话和至少两种表达状态；
- 包含专有名词、多音字、数字或单位；
- 包含至少一个需要人工确认的说话人或校对候选；
- 长度足以测试中断、重试、缓存和章节装配；
- 可以作为内部回归夹具使用，或另行制作可再分发的小型替代夹具。

## 5. 端到端路径

1. 新建项目并登记素材授权；
2. 导入小说并完成人工章节确认；
3. 处理 normalized/corrected 差异；
4. 完成 ScriptUnit、角色、别名和未知说话人审核；
5. 建立 VoiceProfile 和发音词典；
6. 逐 ScriptUnit 生成音频；
7. 执行 QA、人工试听和必要的局部重生成；
8. 生成章节音频和同步时间轴；
9. 导出成品和不含原文/音频的工程配置包；
10. 在新项目重新导入工程包并验证重新绑定；
11. 修改一处文本、一个发音词条和一个音色版本，验证最小过期传播；
12. 汇总指标并形成继续、调整或停止扩展的决定。

## 6. 必测变更场景

- 修改一个 corrected 块，只影响相交 ScriptUnit 和消费者；
- 修改一个 ScriptUnit 说话人，只影响该片段音色和音频；
- 修改一个命中的发音词条，只影响命中片段；
- 激活一个角色的新 VoiceProfile，只影响引用片段；
- 只改审核备注，不使音频过期；
- 调整章节顺序，只使全书目录和发布快照过期；
- 内容改回原值，命中相同输入指纹并复用历史产物；
- 一个产物有两个 stale 原因时，解决一个原因不会恢复为 current。

## 7. 指标

P0 只定义统计方法，不预设未经实测的目标值：

- 文本自动修改接受率、撤销率和每千字审核分钟数；
- 说话人识别准确率、unknown 覆盖率和人工修改率；
- 专有名词、多音字、数字和单位错误率；
- ASR 文本差异及对真实听感问题的召回和误报；
- 每片段生成次数、缓存命中率和永久失败率；
- 角色身份一致性和 Scene 区分度人工评分；
- 每千字 CPU/GPU 时间、峰值显存和存储增长；
- 章节和工程导出成功率；
- 局部修改实际过期数量与预期影响数量的差异。

## 8. 质量门禁

进入下一里程碑前必须满足：

- 当前阶段的阻断 schema 和迁移已确定；
- 关键数据不变量有自动测试；
- 失败和中断可恢复；
- 人工审核入口可用；
- 不存在未登记授权的生产素材；
- 阶段输出可被下游通过正式契约消费；
- 已知问题有责任阶段和处理结论。

## 9. 测试层级

- 单元：纯规则、ID、哈希、范围、差异和状态；
- 契约：格式、LLM、TTS、ASR、音频和工程包适配器；
- 集成：状态库、文件、Provider API、事务、迁移和恢复；
- E2E：项目创建到工程/成品导出；
- 回归：样章固定输入、人工基线和局部变更矩阵；
- 交互：项目切换、影响预览、人工审核、试听和历史比较。

## 10. 完成标准

- M0～M8 均有可复现证据；
- 样章可以从项目创建走到章节成品和工程包；
- 任一输出可追溯到输入、处理器、参数和审核；
- 局部修改不会强制删除或全量重建无关产物；
- 项目重开、中断恢复和工程重新导入通过；
- 指标报告记录继续、调整或停止扩展的决定；
- 不把文档检查或静态目录检查报告为产品功能通过。

## 11. MVP 后续阶段

只有 MVP 数据支持继续扩展时，才评估：

1. 一卷规模压力测试；
2. 复杂音频后期、BGM/SFX 推荐；
3. 完整角色关系和人物时间线；
4. 音色微调工作台和声音资产流水线；
5. 多 Provider 路由和远程任务队列；
6. 多用户、协作、插件和 SDK；
7. Voice/BGM/SFX Library。
