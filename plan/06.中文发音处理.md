# 阶段 06：中文发音处理

状态：`planned`
实现审计：`unverified`
前置阶段：[02 文本校对](./02.文本校对.md)、[03 小说剧本化](./03.小说剧本化.md)

## 1. 目标

从 corrected 和 ScriptUnit 生成独立 `spoken` 层，统一处理数字、日期、单位、英文、缩写、生僻字、多音字、变调和项目专有名词，并支持项目级人工锁定和最小范围回归。

## 2. 范围

- 文本归一化 TN；
- G2P、多音字和变调候选；
- 项目 Pronunciation Dictionary；
- 原文、corrected、spoken 与音素/拼音的定位；
- 词条来源、上下文、优先级、版本和人工锁定；
- 发音审核和影响预览。

## 3. 非目标

- 不修改 corrected 文本；
- 不由 TTS 后端私有格式定义领域词典；
- 不把 ASR 同音字结果直接判定为发音错误；
- 不预设未经样章验证的自动通过阈值。

## 4. 处理优先级

```text
ScriptUnit 人工锁定
> 项目词典人工锁定
> 角色/世界观词典
> 项目规则
> 上下文模型候选
> TTS 后端默认
```

高优先级规则覆盖低优先级时必须记录命中的条目和版本。

## 5. 数据模型

```ts
interface PronunciationEntry {
  entryId: string;
  revisionId: string;
  surface: string;
  reading: string;
  representation: "spoken_text" | "pinyin" | "phoneme" | "engine_hint";
  contextRule?: object;
  effectiveRange?: StoryRange;
  source: "manual" | "dictionary" | "rule" | "model";
  confidence?: number;
  lockedByUser: boolean;
}

interface SpokenUnit {
  scriptUnitId: string;
  correctedText: string;
  spokenText: string;
  alignments: TextAlignment[];
  appliedEntryRevisionIds: string[];
  processorVersion: string;
}
```

后端私有控制标记只能存在于适配器映射层；通用 `spokenText` 必须可独立审核。

## 6. 处理流程

```text
corrected ScriptUnit
→ 数字/日期/单位/缩写 TN
→ 项目词典匹配
→ G2P 和上下文多音字候选
→ 变调/轻声等规则
→ schema 与定位校验
→ 人工审核或策略通过
→ spoken revision
```

候选中文文本前端 PaddleSpeech 文档列出了文本归一化、分词、韵律、G2P、多音字和变调等模块，可用于能力对照，不作为固定依赖：

https://paddlespeech.readthedocs.io/en/latest/tts/zh_text_frontend.html

## 7. 页面和审核

- corrected/spoken/拼音或音素并排显示；
- 高亮数字、单位、英文、专名和多音字；
- 添加项目词条、上下文词条和 ScriptUnit 锁定；
- 查看词条命中范围和受影响片段；
- 使用真实项目文本试听候选读法；
- 修改词条前预览 spoken、音频、QA 和章节影响；
- 从 ASR QA 问题直接进入对应词条或单元。

## 8. 版本和过期影响

- 新增未命中词条不使现有产物过期；
- 修改词条只使实际命中的 SpokenUnit、音频和消费者过期；
- 词条备注变化不使音频过期；
- ScriptUnit 级锁定只影响该单元；
- corrected 内容变化时只重算相交 SpokenUnit；
- 后端 engine hint 改变只影响使用该适配器的生成结果。

## 9. 早期实现迁移

检查旧实现是否：

- 只依赖 TTS 自动读音；
- 直接在原文插入后端控制符；
- 没有 corrected 到 spoken 的定位；
- 项目词典无版本或无人工锁定；
- 修改一个词条使全书重生成；
- 同一术语在各章节使用不同隐藏配置。

词典内容可以迁移，但后端私有字段必须隔离到适配器；无法定位命中范围的旧缓存需要重建索引。

## 10. 测试要求

- 数字、日期、百分数、单位、英文和缩写；
- 人名、地名、术语、生僻字和常见多音字；
- 一词多读的上下文规则；
- 人工锁定优先级；
- corrected/spoken 对齐完整；
- 词条变化只影响命中单元；
- 非法音素或后端提示被适配器校验拒绝。

## 11. 验收标准

- 每个 ScriptUnit 具有可审核 spoken 表达；
- corrected、spoken 和发音表示可以互相定位；
- 人工锁定术语在有效范围内一致；
- 首次出现的项目专名可进入审核队列；
- 词典版本和处理器版本随产物保存；
- 发音变化不会使无命中片段过期。

## 12. 待决策事项

- 通用发音表示采用拼音、音素还是组合；
- 首批 TN/G2P 实现；
- 词典上下文规则表达式；
- TTS 后端不支持指定发音时的降级策略；
- 项目词典导入导出格式；
- 人工审核粒度和自动通过策略。
